Imprint is a financial technology company that builds bespoke co-branded credit cards, deposit accounts, and installment loans for consumer brands such as Shell, Rakuten, and Booking.com. Its Imprint Core platform powers the full lifecycle of a co-branded program - application, card issuance, transactions, rewards, and account management. The public Imprint API (v2) lets partners create customer sessions that hand a client_secret to embeddable Web/iOS/Android SDKs, manage customers and payment methods, track transaction intents and transactions, run reward programs, manage orders, and receive HMAC-signed webhook event notifications. Authentication is via environment-specific API keys (HTTP Basic or Bearer), with separate sandbox and production environments.

**Areas:** Company · Financial Services · Fintech · Credit Cards · Co-Branded Cards · Payments · Loans · Rewards · Loyalty · Embedded Finance
